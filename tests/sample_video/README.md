# Sample video test folder

Everything needed to render and check a sample cartoon, used by
`tests/test_sample_video.py`.

| Path | Purpose |
|---|---|
| `assets/characters/<id>/` | All six characters (cat, kid, adult, dog, car, bicycle): each `character.json` and the images it links to (same layout as the app's `assets/`). |
| `assets/backgrounds/*.jpeg` | `garden`, `forest` and `night` backgrounds. |
| `story.json` | Storyboard rendered into the sample video: 10 scenes, 35 seconds, every character and all three backgrounds. |
| `prompt.txt` | The same story as plain text, for the demo storyboard test. |
| `expected_storyboard.json` | What demo mode must produce from `prompt.txt`. |
| `output/` | Created by the test run (ignored by git). |

## Run

From the `cartoon-studio` folder, with the virtual environment active and FFmpeg installed:

```bash
python -m unittest tests.test_sample_video -v
```

The test renders `story.json` using only the assets in this folder and writes:

- `output/sample.mp4`: the sample video (open it to watch)
- `output/scene-1.png` … `output/scene-10.png`: first frame of each scene
- `output/story.json`: the storyboard that was rendered
- `output/render.log`: FFmpeg messages

Each run replaces the previous output. The test then checks the file with
`ffprobe`: H.264, 640×360, 12 fps, one frame per scene second, the expected
duration, and that frames from different scenes differ. The sample is also
generated by `python -m unittest discover -s tests`.

## Changing the sample

- Edit `story.json` to change the video. Scenes follow the app's rules: at most
  10 scenes, 3–12 seconds each, a `character` from `assets/characters/` and one
  of that character's expressions as `action`.
- Replace files in `assets/` (or run `python -m tools.link_image --characters-dir
  tests/sample_video/assets/characters ...`) to try new artwork without touching
  the app's own assets.
- To refresh this folder after regenerating or relinking the app's characters,
  copy the app's `assets/` folder over `tests/sample_video/assets/`.
- If you change `prompt.txt`, regenerate `expected_storyboard.json`:

  ```bash
  python -c "from app.models import Prompt; from app.storyboard import storyboard; print(storyboard(Prompt(prompt=open('tests/sample_video/prompt.txt').read().strip())).model_dump_json(indent=2))" > tests/sample_video/expected_storyboard.json
  ```
